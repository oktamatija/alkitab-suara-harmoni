# Berkas Installer Alkitab Harmoni Suara

Folder ini merupakan lokasi penyimpanan berkas rilis aplikasi siap pakai (*installer & portable packages*):

- **`Alkitab_Harmoni_Suara_Windows_Setup.exe`**: Installer Windows berbasis Inno Setup (Desktop shortcut, Start menu, Uninstaller).
- **`Alkitab_Harmoni_Suara_Windows_Portable.zip`**: Versi portable Windows (ekstrak langsung jalankan `alkitab_suara_harmoni.exe` tanpa perlu instalasi).
- **`Alkitab_Harmoni_Suara_Android.apk`**: Berkas paket instalasi Android Release.

> Catatan: Berkas biner installer ini juga dapat diunduh langsung dari [GitHub Releases](https://github.com/oktamatija/alkitab-suara-harmoni/releases).
